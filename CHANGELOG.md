# Changelog

## 0.1.0 (first release)
- Native Rust desktop app: workflow builder, notes, text-mode browser, agent panel.
- Workflow nodes: file, notebook, API and SQLite inputs and outputs; text tools; Python and SQL script nodes.
- Local models via Ollama; Claude and OpenAI cloud models with per-node and global privacy gates.
- Settings tab with in-app updates from GitHub Releases (SHA-256 verified).
- Native file picker for file nodes.
- macOS `.app` and `.dmg`, plus Windows and Linux builds.
